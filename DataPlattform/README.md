# Data Pipeline Project

## project description
This is my course project for Data Platforms and Cloud Solutions at Nackademin.  
I wanted to experiment with building a small automated data pipeline in Azure, using Python as the main tool for data generation and uploading.

## What does the pipeline do?
1. **Generate data at the edge:**
   With my Python script (`produce_event_data.py`), I create fake login events or similar data. I wanted to simulate how data could be generated by a sensor or app in the real         world. I chose to use fake login events as sample data, because it’s a common type of event for many real-world applications.
   It allows me to simulate how a sensor, app, or system could send data to the pipeline, and it’s easy to generate in Python.

3. **Send data to Azure Event Hub:**  
   My goal was to send these events to Azure Event Hub, which acts as a queue product in the cloud.  
   I set up Event Hub in my Azure account and used the official Python SDK to show how you would upload messages.

4. **Store data in Azure SQL Database (serverless):**  
   In Azure, I created a serverless SQL database called "Dianas-DB".  
   With my scripts (`import_pyodbc.py`), I can write data directly to the database, and also fetch it for later use.

5. **Consume data:**  
   To complete the flow, I wrote a simple Python consumer that fetches records from the SQL database.  
   Optionally, data can be visualized in Python, or exported for use in other tools like Grafana.

## What is included in this repo?

- **Python scripts:**  
  - `produce_event_data.py` – generates fake events  
  - `import_pyodbc.py` – shows how to send data to both EventHub and SQL DB  
- **Screenshots:**  
  To prove my Azure resources exist and the setup is correct (EventHub, SQL Server, SQL DB, tables, etc.)
- **README.md:**  
  This file, explaining the project.

## What works and what doesn't?

I managed to set up all the Azure resources and connect Python to both EventHub and SQL DB.  
Because of limited access/credits, I did not run all parts live in the cloud, but the scripts show how it would work in practice.

If you want to try it yourself, you need to add your Azure connection strings and credentials to a `.env` file (see `.env.example`).

## How do you run it?

1. Clone the repo:
   ```
   git clone https://github.com/DianaFlodin/Data-pipeline.git
   ```
2. Install the requirements:
   ```
   pip install -r requirements.txt
   ```
3. Add your Azure credentials in `.env`
4. Run the scripts in the terminal:
   ```
   python produce_event_data.py
   python import_pyodbc.py
   ```
   (You can also modify or add your own consumer scripts.)

## Security

Do **not** commit your real Azure secrets to GitHub!  
Always use `.env` files for credentials and connection strings.
